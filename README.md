# connect-ai-sample-agents

Sample agent starter projects for the [CData Connect AI](https://www.cdata.com/connect/) MCP server. Pre-configured templates that connect to your Connect AI MCP server so you can skip the blank-page problem and start with a working codebase.

## Distribution

These templates are published to public registries:

- **npm** — `npx @cdata/connect-ai-sample-agents <template>`
- **PyPI** — `pip install cdata-connect-ai-sample-agents`

(Package names and exact invocation are placeholders until the release pipelines land — see [CLOUD-23459](https://cdatajira.atlassian.net/browse/CLOUD-23459) and [CLOUD-23458](https://cdatajira.atlassian.net/browse/CLOUD-23458).)
